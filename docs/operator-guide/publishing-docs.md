# Publishing these docs

Publish this documentation site on GitHub Pages, using the same `just-the-docs@v0.10.1` theme and palette as isa9000.

1. Confirm the docs are present on GitHub.
2. Select **Settings → Pages → Deploy from a branch**.
3. Select the `main` branch and the `/docs` folder.

This matches isa9000's publishing setup. [GitHub's Pages instructions](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) describe the account/plan requirements.

- **Site URL:** `https://alexandrugirlea.github.io/isa9000-ops/`
- **Scope:** publishing these static instructions does not install the employee application, publish an image or deploy Azure.
- **Content:** keep private company content out of the site.
